Security

What is protected, and what is not

In the browser

  • Ads and trackers blocked Requests to about 130 ad and tracker networks get an empty reply. The page itself is never blocked.
  • Third-party cookies blocked Every tab, always. A site cannot follow you across other sites with a cookie.
  • HTTPS only A plain http address is upgraded to https before it loads.
  • No file or content access A page cannot read files from this device, and cannot open windows on its own.
  • Google Safe Browsing Known phishing and malware pages are flagged before they load.
  • Private tabs No site storage, no cache, third-party cookies off, and cookies wiped when the last one closes.

None of it is a switch. Protection is on by default because a setting nobody turns on protects nobody.

What this page keeps

Your fast dial, favourites, recent searches, opened pages, scratchpad and theme live in this browser's own storage. They are never uploaded — there is no account, no sync, no server of ours to send them to. Clear the site data and they are gone, because nowhere else holds a copy.

What leaves your device

Your searchesGo to Brave, as an ordinary page load. Brave sees them; nothing else does.
The weatherOne request to Open-Meteo with a rounded latitude and longitude. No key, no account.
Site iconsFavicons are fetched from the site itself, then DuckDuckGo, then Google.
Nothing elseNo analytics, no crash reporting, no fingerprinting scripts of our own.

What is not protected

Be clear about the gaps. This is a WebView shell with a host-list blocker, not a hardened browser: it does not stop fingerprinting, it does not isolate every tab, it does not hide your IP from the sites you visit, and a determined tracker on a domain not in the list will get through. Private tabs are ephemeral, not anonymous — Android shares one cookie jar for the whole app, which is why closing the last private tab wipes every cookie you have.

About

Valley · a homepage

Built for both efficiency and privacy

The search

Valley is a front end, not a search engine. It doesn't crawl the web or keep an index — when you press enter, the query goes to Brave Search in an ordinary page load. Brave answers it, and Brave is the only party that sees what you asked. There is no server of ours in between, because there is no server at all: this is static HTML on GitHub Pages.

How a query opens the exact page

Typing oneplus nord ce6 on Flipkart and landing on Flipkart's own search results isn't a search engine being clever. It's a small router, and it runs in this page before anything leaves the browser:

  1. Is it an address? Something like example.com or a full https:// URL goes straight there, untouched.
  2. Does it start with a verb? “open”, “go to”, “visit”, “launch” — followed by a site name or a single word — means go there. open flipkart lands on the Flipkart homepage, open example.com on that address, and open source code is still a search, because two ordinary words are not a destination.
  3. Is it a question? If it ends in ? or starts with what, why, how, is, can, does — it goes to Brave exactly as written. A question that happens to mention a website is still a question.
  4. Does it name a site? A table of about twenty destinations — Flipkart, Amazon, Myntra, Swiggy, YouTube, Wikipedia, GitHub and so on — is checked. If one is named, the query is sent to that site's own search URL, with the site name and any filler like “price of” or “on” stripped out.
  5. Otherwise it goes to Brave.

So it's a shortcut, not mind-reading: the destination is chosen by a rule you can inspect, and the Smart search toggle switches the whole thing off if you'd rather every query went to Brave verbatim.

What stays on your device

Your fast dial, favourites, recent searches, opened pages and scratchpad live in this browser's local storage. They are never uploaded — not to GitHub, not to Brave, not anywhere. The only network call the page makes on its own is to Open-Meteo for the weather, which needs no key and no account. Clear your site data and all of it is gone, because there is nowhere else for it to be.
